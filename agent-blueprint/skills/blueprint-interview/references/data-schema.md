# 설계 데이터 구조

인터뷰 결과를 담는 JSON. 이 구조가 기획서·설계도·세팅 프롬프트 세 산출물의 공통 원본이다.
설계도 HTML 안 `<script id="설계" type="application/json">` 블록에 그대로 들어간다.

키를 한글로 쓰는 이유는 사용자가 열어 볼 수 있어야 하기 때문이다.

---

## 전체 형태

```json
{
  "갈래": {
    "판정": "스킬 | 도구 | 에이전트",
    "이유": "한 문장",
    "선택": "권장대로 | 상위로 변경",
    "원래권장": "스킬 | 도구 | 에이전트 | null"
  },
  "이름": "월간 실적보고 에이전트",
  "한줄목표": "흩어진 실적 파일을 모아 실적보고서를 쓰고 팀장에게 보낸다",
  "만든날짜": "2026-07-31",
  "만든사람": "이름 또는 null",

  "결과물": {
    "이름": "월간 실적보고서",
    "형식": "docx",
    "전달방식": ["파일로 남는다", "누군가에게 보낸다"],
    "받는사람": "팀장",
    "주기": "매월 1회",
    "완성기준": ["표 합계가 원본과 일치", "3장 이내"]

  "입력": {
    "매번바뀜": [
      { "이름": "이번 달 실적 엑셀", "형식": "xlsx", "출처": "부서 공유폴더" }
    ],
    "고정참조": [
      { "이름": "보고서 서식 파일", "형식": "docx" }
```

`세팅프롬프트`는 `세팅_프롬프트.md`와 **같은 본문**을 문자열로 담는다. 설계도의 복사 버튼이 이 값을 쓰기 때문에, 인터넷 없이도 버튼이 동작한다.

## 필드 규칙

### 갈래

| 필드 | 규칙 |
|------|------|
| `판정` | `스킬` · `도구` · `에이전트` 중 하나. 반드시 채운다 |
| `이유` | 한 문장. 판정 근거가 된 답을 그대로 인용한다. 예: "자료가 한 곳이고 중간에 확인할 지점이 없어서" |
| `선택` | 사용자가 권장을 따르면 `권장대로`, 상위 갈래로 올렸으면 `상위로 변경` |
| `원래권장` | `선택`이 `상위로 변경`일 때만 원래 판정을 넣는다. 아니면 `null` |

### 결과물

| 필드 | 규칙 |
|------|------|
| `형식` | 확장자 또는 형태. `docx` `xlsx` `pptx` `pdf` `hwpx` `csv` `웹페이지` `메일` 등 |
| `전달방식` | 배열. `파일로 남는다` · `누군가에게 보낸다` · `여러 사람이 보는 화면에 올린다` · `다른 사람이 각자 실행해서 쓴다` 중 1개 이상 |
| `완성기준` | 0~4개. 비면 설계도에 "아직 안 정함" |

### 입력

| 필드 | 규칙 |
|------|------|
| `매번바뀜[].출처` | **갈래·병렬 판정의 근거.** 서로 다른 출처의 개수를 센다. 모르면 `"미정"` |
| `고정참조` | 서식·기준표·지난 문서 등 |
| `머릿속규칙` | **가장 중요한 필드.** 비면 설계도에 경고를 띄운다 |

### 과정

| 필드 | 규칙 |
|------|------|
| `순서` | 1부터 연속. 3~8개 |
| `담당` | `AI` · `사람` · `AI+확인` 중 하나 |
| `병렬그룹` | 같은 번호끼리 동시 실행으로 그린다. 순차면 `null` |
| `루프대상` | 이 단계가 끝난 뒤 되돌아갈 단계 번호. 평가 담당 단계에만 넣는다. 아니면 `null` |
| `병목` | `true`는 **최대 2개**. 3개 이상 고르면 되묻는다 |

### 범위

`이번에만들것`과 `다음에`의 합집합 = 전체 단계 번호. 겹치지 않는다.

### 부품

**여섯 칸은 항상 존재한다.** 안 쓰더라도 키를 지우지 않는다. `쓴다: false`이면 `안쓰는이유`를 한 구절로 채운다 (예: "받는 사람이 한 명이라").

| 부품 | 쓸 때 채우는 필드 |
|------|-----------------|
| `스킬` | `내용` — `"형식 — 용도"` 형태의 문자열 배열 |
| `나눠서동시에` | `내용` — 담당 이름 배열 (예: `["실적 담당", "지출 담당"]`) |
| `평가담당` | `기준` (배열, 반려사유에서 가져옴) + `종료조건` (문자열, 비우지 않는다) |
| `보내기연결` | `내용` — 무엇으로 보내는지 (예: `"메일 발송"`) |
| `혼자도는도구` | `단계` — `"로컬 웹앱"` 또는 `"실행 파일"`. `실행 파일`이면 `웹앱으로안되는이유` 필수 |
| `보여주는페이지` | `내용` — 무엇을 보여주는 페이지인지 |

### 구성

갈래에 따라 채우는 범위가 다르다.

| 갈래 | `폴더` | `지시요지` | `사람확인지점` |
|------|--------|-----------|--------------|
| 스킬 | `[]` (빈 배열) | 스킬이 지킬 규칙 | `[]` |
| 도구 | `[]` | 처리 규칙 | `[]` |
| 에이전트 | 폴더 이름 배열 | 에이전트 지시 요지 | 사람이 볼 단계 |

폴더를 만들지 않는 갈래에서 `폴더`를 채우지 않는다. 만들지도 않을 폴더 이름이 설계도에 뜨면 사용자가 그게 이미 있는 줄 안다.

### 미정

답을 못 받은 항목을 문자열로 기록한다. 설계도 하단에 "아직 안 정함"으로 뜬다.

---

## 담지 않는 것

**문서 본문·실제 수치·개인정보를 넣지 않는다.** 항목명·구조·규칙만 담는다.
설계도는 서로 공유하는 산출물이므로 구조 단계에서 막는다.

| 넣는다 | 넣지 않는다 |
|--------|-----------|
| `"표 3열 — 부서별 집행액"` | `"영업2팀 3,240만원"` |
| `"참석자 명단 항목 있음"` | `"김○○, 이○○"` |
| `"금액은 천 원 단위 반올림"` | 실제 금액 |

### 도구

`부품.혼자도는도구.쓴다 = true`, `단계 = "로컬 웹앱"`이 기본. `구성.폴더 = []`.
`과정`은 버튼을 누른 뒤 일어나는 처리 순서를 적는다.
