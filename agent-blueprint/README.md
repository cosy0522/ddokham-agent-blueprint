# 에이전트 설계도 (agent-blueprint)

내 업무를 AI에게 맡기고 싶은데 무엇부터 만들어야 할지 모를 때 쓰는 플러그인입니다.

질문 열한 개에 답하면 두 가지가 나옵니다.
하나는 **내 업무에 맞는 것이 무엇인지**에 대한 답이고, 다른 하나는 **그것을 만들기 위한 문서 세 개**입니다.

모든 업무에 에이전트가 필요한 것은 아닙니다.
자료 하나로 문서 하나 만드는 일에 에이전트를 세우면 관리할 것만 늘어납니다.
이 플러그인은 답변을 보고 세 갈래 중 하나를 골라 주고, 왜 그렇게 판단했는지 이유를 함께 보여 줍니다.

| 갈래 | 만드는 것 | 어디서 쓰나 |
|------|----------|-----------|
| 스킬 | 스킬 하나 | 계정에 올려 두고 어디서든 |
| 도구 | 버튼 화면이 있는 도구 | 내 PC, 필요하면 동료에게 |
| 에이전트 | 폴더와 지시와 부품 | Claude Code |

## 쓰는 법

만들고 싶은 결과물 파일이 들어 있는 폴더를 Claude Code로 엽니다.
그리고 `/ddokham-blueprint`를 칩니다. 그게 전부입니다.

파일이 없어도 됩니다. 준비된 예시 네 가지 중에서 고르면 됩니다.

## 커맨드 두 개

| 커맨드 | 하는 일 |
|--------|--------|
| `/ddokham-blueprint` | 질문에 답하면 파일 세 개를 만들어 줍니다 |
| `/ddokham-blueprint-redraw` | 기획서를 고친 뒤 나머지 둘을 다시 만듭니다 |

`/ddo`까지만 쳐도 둘 다 목록에 뜹니다.

## 만들어지는 파일 세 개

폴더 안에 `설계도` 폴더가 하나 생기고 그 안에 들어갑니다.

| 파일 | 무엇인가 |
|------|---------|
| `기획서.md` | 사람이 읽고 직접 고치는 문서입니다. 여기가 원본입니다 |
| `설계도.html` | 전체 흐름을 한 장 그림으로 본 것입니다. 더블클릭하면 브라우저에서 열립니다 |
| `세팅_프롬프트.md` | 실제로 만들 때 그대로 붙여 넣을 프롬프트입니다 |

설계도를 보다가 고칠 곳이 보이면 `기획서.md`를 고치고 `/ddokham-blueprint-redraw`를 치면 됩니다.
인터뷰를 처음부터 다시 하지 않아도 됩니다.

## 이 플러그인이 하지 않는 것

**설계만 합니다. 아무것도 초기화하지 않습니다.**

폴더도, 설정 파일도, `CLAUDE.md`도 만들지 않습니다.
새로 생기는 것은 `설계도` 폴더와 그 안의 파일 세 개뿐입니다.

실제로 만드는 일은 다음 단계이고, 그때 `세팅_프롬프트.md`를 쓰면 됩니다.

## 설치하는 법

### 방법 1 — 마켓플레이스에서 설치 (권장)

1. Claude Code를 엽니다.
2. `/plugin marketplace add` 뒤에 저장소 주소를 붙여 입력합니다. 주소는 따로 안내받습니다.
3. `/plugin install agent-blueprint`를 입력합니다.
4. `/ddo`를 쳐서 커맨드 두 개가 뜨면 설치된 것입니다.

### 방법 2 — 폴더 복사

네트워크가 막혀 있거나 설치가 안 될 때 쓰는 방법입니다.

1. `agent-blueprint` 폴더를 받습니다.
2. 그 안의 `commands` 폴더와 `skills` 폴더를, 작업할 폴더 안의 `.claude` 폴더에 복사해 넣습니다. `.claude` 폴더가 없으면 만듭니다.
3. Claude Code를 다시 엽니다.
4. `/ddo`를 쳐서 커맨드 두 개가 뜨면 된 것입니다.
