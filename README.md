# 에이전트 설계도

내 업무를 AI에게 맡기고 싶은데 무엇부터 만들어야 할지 모를 때 쓰는 Claude Code 플러그인입니다.

질문 열한 개에 답하면, **내 업무에 맞는 것이 무엇인지** 판정하고 **문서 세 개**를 만들어 줍니다.

코딩을 모르는 사람을 위해 만들었습니다. 질문은 모두 보기에서 고르는 형태이고, 답을 모르면 넘어가도 됩니다.

---

## 설치

Claude Code에서 두 줄이면 됩니다.

```
/plugin marketplace add Merciless-Hamster/ddokham-agent-blueprint
/plugin install agent-blueprint@ddokham
```

## 쓰는 법

만들고 싶은 결과물 파일이 들어 있는 폴더를 Claude Code로 열고, 이렇게 칩니다.

```
/ddokham-blueprint
```

그게 전부입니다. 가져온 파일이 없어도 준비된 예시 네 가지 중에서 고르면 됩니다.

| 커맨드 | 하는 일 |
|--------|--------|
| `/ddokham-blueprint` | 질문에 답하면 파일 세 개를 만들어 줍니다 |
| `/ddokham-blueprint-redraw` | 기획서를 고친 뒤 나머지 둘을 다시 만듭니다 |

---

## 무엇이 나오나

폴더에 `설계도/`가 생기고 그 안에 세 개가 들어 있습니다.

| 파일 | 무엇 |
|------|------|
| `기획서.md` | 무엇을 왜 만드는지 적은 문서. 직접 고쳐도 됩니다 |
| `설계도.html` | 한 장짜리 그림. 브라우저로 열고, 인쇄하면 A4 가로 한 장입니다 |
| `세팅_프롬프트.md` | 실제로 만들 때 붙여 넣는 프롬프트 |

설계도는 재료에서 결과물까지의 흐름을 한 장에 담습니다. AI가 하는 단계와 사람이 봐야 하는 단계를 색으로 나누고, 동시에 도는 일은 묶어서, 되돌아가 고쳐 쓰는 구간은 화살표로 그립니다. 서로 보여 주고 이야기하기 위한 그림입니다.

---

## 모든 업무에 에이전트가 필요한 건 아닙니다

자료 하나로 문서 하나 만드는 일에 에이전트를 세우면 관리할 것만 늘어납니다.
이 플러그인은 답변을 보고 세 갈래 중 하나를 골라 주고, **왜 그렇게 판단했는지 이유를 함께** 보여 줍니다.

| 갈래 | 언제 | 만드는 것 | 어디서 쓰나 |
|------|------|----------|-----------|
| **스킬** | 자료 한두 개로 매번 같은 서식의 문서를 만들 때 | 스킬 하나 | 계정에 올려 두고 어디서든 |
| **도구** | 판단은 없고 손만 많이 가는 반복 작업일 때 | 버튼 화면이 있는 도구 | 내 PC, 필요하면 동료에게 |
| **에이전트** | 여러 곳에서 모아 판단이 섞인 결과물을 만들 때 | 폴더와 지시와 부품 | Claude Code |

애매하면 낮은 쪽을 먼저 권합니다. 크게 만들면 고칠 것도 커지기 때문입니다.
권한 판정이 마음에 안 들면 위 갈래로 올릴 수 있고, 그 사실이 기획서에 남습니다.

반복 작업 도구는 **버튼 화면부터** 만듭니다. 쓰는 사람이 명령어를 치게 하지 않습니다.

---

## 이 플러그인이 하지 않는 것

- 실제로 만들어 주지 않습니다. 설계까지가 이 플러그인의 몫이고, 만드는 것은 세팅 프롬프트가 이어받습니다
- 폴더나 설정 파일을 미리 만들지 않습니다. 생기는 것은 `설계도/` 안 세 개뿐입니다
- 문서 내용이나 실제 숫자를 설계도에 담지 않습니다. 항목 이름과 구조만 담습니다. 서로 보여 주는 그림이기 때문입니다
- 어디로도 올리지 않습니다. 전부 내 컴퓨터 안의 파일입니다
